## Ten mechanisms

1. **Separate diagnostics from execution preflight.** `doctor team-routing` probes configured provider binaries, reports paths/versions and JSON, and intentionally exits successfully when providers are missing. Actual team startup instead resolves effective task ownership and role assignments, pins absolute provider binary paths, and rejects unusable selected providers before creating team state, worktrees, or panes. Adaptation: a friendly `doctor --json` plus a strict run admission check over the complete selected flow roster. Presence/version probes do not establish authentication or successful provider requests. Sources: [doctor command](https://github.com/Yeachan-Heo/oh-my-claudecode/blob/e252e55e34bc3d86fa5d02149688b316eea954f5/src/cli/commands/doctor-team-routing.ts), [startup admission](https://github.com/Yeachan-Heo/oh-my-claudecode/blob/e252e55e34bc3d86fa5d02149688b316eea954f5/src/team/runtime-v2.ts#L4040-L4124).

2. **Expose structured pre-run findings.** `lookout` returns stable rule IDs, severity, confidence, evidence, advice, and an aggregate verdict; its CLI supports JSON and a strict exit status for high-risk signals. It scans briefing/workspace signals rather than proving a task safe. It is advisory and does not itself block execution. Adaptation: explicit preflight policy with auditable evidence and configurable admission, avoiding claims of a security sandbox. Sources: [report contract](https://github.com/Yeachan-Heo/oh-my-claudecode/blob/e252e55e34bc3d86fa5d02149688b316eea954f5/src/features/lookout/types.ts), [CLI semantics](https://github.com/Yeachan-Heo/oh-my-claudecode/blob/e252e55e34bc3d86fa5d02149688b316eea954f5/src/cli/lookout.ts#L76-L120).

3. **Make context limits executable.** Read-budget preflight checks whole-file reads against byte and line thresholds, with warn/deny modes, allowlists, targeted-read exemptions, and an explicit off switch. This is a context-volume limit, not a monetary budget; shell coverage deliberately handles only bare `cat`, not arbitrary data access. State writes also have byte, depth, and key-count validation. Adaptation: enforce bounded context assembly and persisted payloads at llm4ts-owned boundaries. Sources: [read evaluator](https://github.com/Yeachan-Heo/oh-my-claudecode/blob/e252e55e34bc3d86fa5d02149688b316eea954f5/scripts/lib/read-budget-preflight.mjs#L1-L66), [payload validator](https://github.com/Yeachan-Heo/oh-my-claudecode/blob/e252e55e34bc3d86fa5d02149688b316eea954f5/src/lib/payload-limits.ts).

4. **Measure host pressure before admitting concurrency.** A host-load module measures cores-relative load, free memory, and sibling session directories with configurable thresholds and bounded waiting. Crucial limitation: the inspected worker-launch integration calls the check and explicitly proceeds on denial; it is advisory there. Directory counting also does not establish that each session remains live. Adaptation: real bounded admission/backpressure with observable wait reasons and a deliberate timeout policy, rather than copying the integration. Sources: [metrics and policy](https://github.com/Yeachan-Heo/oh-my-claudecode/blob/e252e55e34bc3d86fa5d02149688b316eea954f5/src/lib/host-load-gate.ts), [actual launch behavior](https://github.com/Yeachan-Heo/oh-my-claudecode/blob/e252e55e34bc3d86fa5d02149688b316eea954f5/src/team/worker-launch-ack.ts#L2062-L2072).

5. **Distinguish command failure from execution infrastructure failure.** The graph command executor bounds captured output, imposes timeout termination, escalates killing the process group on POSIX, and uses Windows tree termination. Children receive an allowlisted environment. Arbitrary shell execution remains trusted descriptor-author authority. Adaptation: verify descendant cleanup, bounded output, and classified timeout/spawn failures in the common process service. Source: [command executor](https://github.com/Yeachan-Heo/oh-my-claudecode/blob/e252e55e34bc3d86fa5d02149688b316eea954f5/src/graph/runtime/executors/command.ts#L1-L137).

6. **Recover ownership as a state transition.** Task recovery checkpoints bind worker, task version, claim token, sequence, and payload hash; payloads are capped at 64 KiB and immutable publication detects conflicting replays. A recovery saga checks liveness and checkpoints before requeueing, gates replacement activation, adopts continuations, and records partially committed outcomes. Adaptation: preserve attempt identity and explicit uncertain outcomes across crashes instead of treating every restart as a fresh retry. Sources: [checkpoint protocol](https://github.com/Yeachan-Heo/oh-my-claudecode/blob/e252e55e34bc3d86fa5d02149688b316eea954f5/src/team/task-recovery-checkpoint.ts), [recovery saga](https://github.com/Yeachan-Heo/oh-my-claudecode/blob/e252e55e34bc3d86fa5d02149688b316eea954f5/src/team/recovery-saga.ts).

7. **Persist control decisions and replayable transitions.** The graph runtime uses an append-only journal binding sequence, writer epoch, descriptor hash, and transition fingerprint. Approval denial is a first-class outcome; terminal EOF fails closed, while remote approval supports timeout policy. Adaptation: durable approval/resume states and fenced replay if llm4ts needs cross-process control. This graph subsystem should not be conflated with all OMC workflows. Sources: [journal](https://github.com/Yeachan-Heo/oh-my-claudecode/blob/e252e55e34bc3d86fa5d02149688b316eea954f5/src/graph/runtime/journal.ts), [terminal approval](https://github.com/Yeachan-Heo/oh-my-claudecode/blob/e252e55e34bc3d86fa5d02149688b316eea954f5/src/graph/runtime/approval.ts), [remote approval](https://github.com/Yeachan-Heo/oh-my-claudecode/blob/e252e55e34bc3d86fa5d02149688b316eea954f5/src/graph/runtime/remote-approval.ts).

8. **Pass artifact references instead of duplicating large bodies.** The shared artifact handoff uses inline text below a configurable threshold (default 2,048 bytes), otherwise a short summary plus descriptor containing path, hash, producer, size, and retention. Adaptation: typed large-result references for plans, reviewer evidence, and extraction outputs; validate reference containment and freshness separately. Source: [artifact handoff contract](https://github.com/Yeachan-Heo/oh-my-claudecode/blob/e252e55e34bc3d86fa5d02149688b316eea954f5/src/shared/artifact-descriptor.ts).

9. **Keep durable context distinct from transient transcripts.** Project memory stores directives, hot paths, stack information, and notes; compaction reinjects a summary. Storage uses atomic writes, cross-process locking, and normalization for older records. Validation is basic and storage failures are intentionally tolerated. Adaptation: bounded, schema-validated, provenance-bearing project context without treating learned text as new user authority. Sources: [storage](https://github.com/Yeachan-Heo/oh-my-claudecode/blob/e252e55e34bc3d86fa5d02149688b316eea954f5/src/hooks/project-memory/storage.ts), [compaction summary](https://github.com/Yeachan-Heo/oh-my-claudecode/blob/e252e55e34bc3d86fa5d02149688b316eea954f5/src/hooks/project-memory/pre-compact.ts).

10. **Evaluate reviewer behavior, including clean examples.** The reviewer benchmark pairs deliberately flawed fixtures with ground truth and clean baselines, scoring detection, evidence, perspective coverage, and false positives. It archives the old comparison prompt. Matching is keyword based, the fixture set is small, and the README recommends repeated runs/model pinning: this is useful infrastructure, not independent proof of broad superiority. Adaptation: versioned llm4ts flow/pack evaluations for acceptance accuracy, regressions, cost, and recovery behavior. Sources: [benchmark methodology](https://github.com/Yeachan-Heo/oh-my-claudecode/blob/e252e55e34bc3d86fa5d02149688b316eea954f5/benchmarks/harsh-critic/README.md), [shared scorer](https://github.com/Yeachan-Heo/oh-my-claudecode/blob/e252e55e34bc3d86fa5d02149688b316eea954f5/benchmarks/shared/scorer.ts).

## Interpretation limits

The [landing page](https://oh-my-claudecode.dev/) combines product positioning, execution modes, and automatic-routing claims. The pinned [README](https://github.com/Yeachan-Heo/oh-my-claudecode/blob/e252e55e34bc3d86fa5d02149688b316eea954f5/README.md) distinguishes native in-session teams from CLI/tmux workers and documents platform limits for named stage profiles. The older [delegation resolver](https://github.com/Yeachan-Heo/oh-my-claudecode/blob/e252e55e34bc3d86fa5d02149688b316eea954f5/src/features/delegation-routing/resolver.ts) even maps deprecated Codex/Gemini MCP routes back to Claude Task. Thus model/provider routing must be assessed per runtime; specialist counts and broad “automatic” claims are not reliable acceptance criteria. No evidence here establishes active run-wide monetary budget enforcement.
