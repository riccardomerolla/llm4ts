The name is Marvin, the android from The Hitchhiker's Guide to the Galaxy: a brain the size of a planet, given chores, and convinced it will all go wrong. That is a fair picture of a coding agent, which is exactly why the method never takes its word for anything.

Rewriting it by hand never happens. It is never urgent, the people who know it are busy keeping it running, and nobody can prove the new system behaves like the old one. That last point is what Marvin was built for.

The reason the rewrite never happens is not money. It is that nobody can sign off that the new system is equivalent. Keep that word, equivalent: the demo ends on it.

The idea

Agents do the volume.
People make the decisions.

Supervised at the decisions: the plan, the specification, the merge. Everything between them is a flow that runs on its own and writes down every step.

  1. 01Only reviewed work is committed. The build and a second agent check every change. The agent never grades its own work.
  2. 02Every step is a file in our repository. Plan, findings, progress, verdict. Stop a run anywhere, resume it anywhere.
  3. 03The agent is a seat. Gemini CLI today, through our Vertex AI project; a local model where data must not leave. Code and data stay inside our perimeter.
